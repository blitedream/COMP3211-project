# COMP3211-project
COMP3211 Group Project

## Member A PIR core

The Java implementation for US1-US6 is in `src/main/java/model/`.
Its unit tests are in `src/test/java/model/`. On Windows, run
`./run_tests.ps1` to compile and execute the tests. See
`docs/A_README.md` for the module scope and `docs/A_core_design.md`
for the public API and integration contract. The editable SRS draft is
`docs/PIM_SRS_Draft.docx`.
